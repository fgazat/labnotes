**Металлургия** — получение металлов из руд и их очистка. Её делят на чёрную и цветную:

| Чёрная металлургия | Цветная металлургия |
|---|---|
| железо и его сплавы (чугуны, стали); марганец и хром | **лёгкие** металлы: алюминий, титан, магний |
| | **тяжёлые**: кобальт, никель, медь, цинк, свинец |
| | **редкие**: молибден, вольфрам, литий |
| | **платиновые** металлы: платина и другие |
| | **редкоземельные** и **радиоактивные** |
