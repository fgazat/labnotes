## Механизм анионной полимеризации

Анионная полимеризация характерна для винильных соединений с электроноакцепторными заместителями: акрилонитрила, алкилакрилатов, стирола и др.

![Смещение электронной плотности](/images/anionnaya-polimerizaciya/Anion_clip_image001_0003.png)

### Основные стадии:

1. Инициирование

    ![Инициирование анионной полимеризации](/images/anionnaya-polimerizaciya/Anion_clip_image001_0004.png)

    Причем "Х" — не галоген. Галогензамещенные винилы не вступают в такую реакцию, они малоактивны (ПВХ получают по радикальному механизму).

2. Рост цепи

    ![рост цепи](/images/anionnaya-polimerizaciya/Anion_clip_image001_0005.png)

3. Реакция обрыва цепи (протекает с участием растворителя, например аммиаком)

    ![Обрыв цепи](/images/anionnaya-polimerizaciya/Anion_clip_image001_0006.png)

Анионная полимеризация используется для получения полимеров узкого молекулярно-массового распределения (цепочки одной длины)


## Получение блок-сополимеров

«Живые» цепи позволяют последовательно наращивать блоки разных мономеров. Например, при полимеризации стирола под действием натрия (через анион-радикал) образуется «живой» полистирол с активными центрами —CH₂⁻ Na⁺ на обоих концах. Если затем добавить бутадиен CH₂=CH–CH=CH₂, он полимеризуется с обоих концов, и получается трехблочный сополимер: полибутадиен — полистирол — полибутадиен.

![Получение блок-сополимера: n молекул стирола → «живой» полистирол Na⁺⁻CH₂–CH(Ph)–[CH₂–CH(Ph)]ₘ–CH(Ph)–CH₂⁻Na⁺; + бутадиен → [CH₂–CH=CH–CH₂]ₙ–(полистирольный блок)–[CH₂–CH=CH–CH₂]ₙ; схема: гибкий блок — жесткий блок — гибкий блок](/images/anionnaya-polimerizaciya/blok-sopolimer-stirol-butadien.png)

Реакцию нельзя отнести к сшиванию, так как сетка не образуется: получаются линейные макромолекулы, в которых гибкие полибутадиеновые блоки чередуются с жестким полистирольным.

Для сравнения — другие архитектуры цепей:

![Гибкая цепь (клубок); жесткая цепь из жестких сегментов; гребнеобразный полимер с жесткими боковыми группами на гибкой основной цепи](/images/anionnaya-polimerizaciya/arhitektura-cepej.png)

- **Гибкая цепь** сворачивается в клубок.
- **Жесткая цепь** состоит из жестких фрагментов.
- **Гребнеобразные полимеры** с жесткими (мезогенными) боковыми группами на гибкой основной цепи образуют растворы, обладающие жидкокристаллическим упорядочением.
